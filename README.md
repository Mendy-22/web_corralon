# 🧱 Corralón Gran Unión

Sitio web para un corralón de materiales de construcción. Incluye catálogo interactivo, login, carrito, formulario de envío y contacto por WhatsApp.

## 🚀 Tecnologías usadas

- HTML semántico
- CSS con diseño responsive
- JavaScript modular
- LocalStorage para login y carrito
- Toasts modernos para feedback
- GitHub Pages para publicación

## ✅ Buenas prácticas aplicadas

- Separación clara de estructura, estilos y lógica
- Validación de formularios y contraseñas
- Efectos visuales suaves y accesibles
- Organización prolija del repositorio
- Comentarios explicativos en el código
